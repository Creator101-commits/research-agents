# Dairy ABM Build Plan

This plan tracks the implementation of the agents described in `abm_blueprint.html`.

## Build Rules

- Build Agents 1-12 as the default runtime.
- Keep Agent 13 disabled unless `enable_land_agent` is true.
- Keep all blueprint-unspecified coefficients in a calibration file and expose them in a calibration inventory.
- Use a dependency-free Python package and CLI for the first build.
- Add tests before marking the task done.
- Run `python3 -m unittest discover -s tests -p 'test_*.py'` after each completed step.
- Run `bun test` before final delivery only because the repo instructions require it.

## Circular Bioeconomy Loop Closure

### Constraints

- Preserve the existing daily scheduler order. Feed/Crop must continue to run before Dairy Processor, Manure, and Water.
- Implement L1, L2, and L4 through persistent credits that are consumed by Feed/Crop on the following day only.
- Keep L3 self-contained in Energy; it remains a Farm Manager value/cost input rather than a cross-agent mass transfer.
- Do not introduce same-day feedback paths or reorder agents.
- All newly introduced calibration coefficients must carry complete calibration metadata. Coefficients not precisely specified by the blueprint or dashboard must use `assumption: true`.
- Add tests before each loop implementation and run the Python test suite after every changed file, then again as the final gate. Run `bun test` before final delivery.
